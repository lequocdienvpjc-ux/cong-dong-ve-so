# Cộng Đồng Mưu Sinh

**Kết nối bằng công nghệ – Chia sẻ bằng tình người.** Nền tảng cộng đồng miễn phí kết nối đại lý vé số, người bán vé số dạo / cố định, người mua và người muốn hỗ trợ tại Việt Nam.

> Ứng dụng chỉ cung cấp thông tin và kết nối. **Không** có chức năng đặt mua, thanh toán, giao, chuyển nhượng hay phân phối vé số.

- Ứng dụng web / iPhone (PWA): https://lequocdienvpjc-ux.github.io/cong-dong-ve-so/
- Trang quản trị: https://lequocdienvpjc-ux.github.io/cong-dong-ve-so/#/admin
- APK Android mới nhất: https://github.com/lequocdienvpjc-ux/cong-dong-ve-so/releases/latest/download/CongDongVeSo.apk

Công nghệ: React + Vite (PWA), Capacitor (Android), Supabase (PostgreSQL, Auth, RLS), GitHub Actions, GitHub Pages.
Tài liệu: thư mục `documents/` và `deployment/`.
