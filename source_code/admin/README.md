# Website quản trị

Trang quản trị dùng chung mã nguồn với ứng dụng (thư mục `../frontend/src/admin/`) để luôn dùng chung dữ liệu và phiên bản.
Địa chỉ: xem `web_admin/WEB_ADMIN_LINK.txt` (đường dẫn `.../#/admin`).
Quyền được kiểm tra ở database (Row Level Security + hàm `is_staff/is_admin/is_super_admin`), không chỉ ở giao diện.
